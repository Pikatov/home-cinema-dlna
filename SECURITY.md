# Security Policy

## Сообщить об уязвимости
- Используйте GitHub Security Advisory или откройте private security issue в репозитории.
- Не публикуйте эксплойты в публичных issue и не прикладывайте пользовательские данные или реальные медиапути.

## Поддерживаемые версии
- Текущая `main` ветка. Исправления публикуются через патчи/релизы по мере необходимости.

## Что приложить к отчёту
- Версия (коммит хэш) и платформа (macOS версия).
- Минимальные шаги воспроизведения и лог-фрагменты без персональных путей или имён файлов с людьми.
- Ожидаемое vs фактическое поведение.

## Ответ
- Подтверждение получения — в течение 7 рабочих дней.
- При принятии — выпуск фикса и уведомление через релиз/адвайзори.
