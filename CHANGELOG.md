# Changelog

## 1.8.1 — 2026-06-14
- Fix: прямой `/video/` больше не отменяет стартовый поток, когда DLNA-клиент сразу после запроса без `Range` открывает `Range` с нулевого байта; это устраняет цикл повторных попыток воспроизведения на части ТВ.
- macOS app: `ffmpeg` и `ffprobe` теперь вкладываются в `.app` вместе с нужными Homebrew-библиотеками, поэтому TV-поток работает на другом Mac без отдельной установки `ffmpeg`.
- Streaming: если длительность файла ещё не прогрета, крупные `.mkv`/`.webm` всё равно получают совместимый TV-поток первым ресурсом вместо прямого `/video/`.

## 1.8 — 2026-05-31
- macOS app: новый интерфейс управления с live-блоком `ON AIR`, списком активных стримов, более спокойной навигацией и undo для сброса прогресса.
- Now playing: добавлен лёгкий `/stats` endpoint и учёт активных сессий для прямого, TV и resume-потоков; приложение показывает устройство, тип потока и текущий таймкод.
- TV playback: для тяжёлых файлов и HEVC/HDR MKV сервер по умолчанию поднимает совместимый ffmpeg TV-поток выше оригинала, ограничивает число транскодов и отменяет старый поток при reconnect/seek.
- DLNA duration: потокам добавлены более полные заголовки длительности и time-seek (`Content-Duration`, `TimeSeekRange.dlna.org`, `X-Content-Duration`, `X-AvailableSeekRange`), чтобы больше ТВ видели конец фильма.
- Metadata: длительность теперь быстрее восстанавливается из кеша, Matroska-заголовка или сохранённого прогресса; отрицательные результаты `ffprobe` кешируются на короткое время, чтобы не долбить битые файлы.
- Progress: сохранение прогресса стало аккуратнее при probe-запросах, удалённые из медиатеки файлы вычищаются на старте, при смене папки и периодически раз в час.
- Streaming: прямой `/video/` остался обычной отдачей с `Range`, `/tv/` стал устойчивее на больших файлах, `/resume/` отдаёт виртуальный хвост файла с корректными HTTP/DLNA-заголовками.
- Repo and release: версия поднята до `1.8`, macOS app теперь требует macOS 14+, добавлены тесты для сессий, time-seek, прогресса, путей и DLNA-поведения.

## 1.7 — 2026-04-14
- macOS app: интерфейс переработан в более цельный glass-style control deck с `Auto/Light/Dark` темой, анимированным фоном, аккуратными hover/press-состояниями и более собранной компоновкой главного окна.
- Progress UX: блок сохранённого прогресса стал компактнее и спокойнее визуально, получил тонкий progress bar, улучшенное отображение папки/времени и более аккуратное inline-удаление записей.
- Resume accuracy: при старте фильма с уже сохранённой позиции сервер теперь продолжает сохранять прогресс от фактического seek-оффсета, а не пересчитывает его заново от начала файла.
- Repo cleanup: удалены устаревшие placeholder-файлы SwiftUI в `build/home-cinema/HomeCinemaControlSwift/`, актуальные `Package.swift` и `Sources/HomeCinemaControlSwift/*` больше не скрываются ошибочным правилом в `.gitignore`.
- Release prep: обновлены README на русском и английском, подготовлены release notes и assets для версии `1.7`.

## 1.6 — 2026-04-12
- macOS app: интерфейс стал заметно компактнее и чище; убраны лишние секции и повторы статусов, обновлена терминология действий, а основное окно стало ближе к одному понятному control deck вместо перегруженного дашборда.
- Progress UX: кнопка `Refresh` заменена на `Reset Progress`, в приложении появился список файлов с сохранённым прогрессом, удаление отдельных записей из UI и более стабильная сортировка без "скачущих" строк.
- Resume playback: для фильмов с сохранённым прогрессом сервер теперь надёжнее запускает воспроизведение с места остановки; это поведение отдельно задокументировано вместе с ограничением, что после такого старта на части DLNA-клиентов может пропасть перемотка и отображение оставшегося времени.
- Progress data: приложение теперь автоматически убирает устаревшие записи прогресса для файлов, которых уже нет в текущей медиатеке, поэтому список и счётчик больше не показывают удалённые фильмы.
- Control API: добавлены и доведены до рабочего состояния сценарии сброса всего прогресса и удаления одной записи прогресса через локальные control-endpoints и офлайн-режим приложения.
- Release prep: расширен `.gitignore` для локальных Swift/Go-артефактов, бинарников, `.app`, pid-файлов и кешей; README на русском и английском переписаны под актуальный workflow, добавлены release notes для версии `1.6`.

## 1.5 — 2026-04-08
- Refactor: сервер разбит на отдельные Go-файлы по зонам ответственности (`streaming`, `progress`, `browse`, `metadata`, `events`, `ssdp`, `control`, `xml`, `helpers`).
- Progress: сохранение прогресса сделано атомарным и устойчивым к рестартам клиента; байтовый прогресс теперь хранит длительность, есть финальный flush при остановке сервера и защита от затирания прогресса ранними probe-запросами.
- Streaming: снижены риски фризов за счёт ограничения ожидания `ffprobe`, pause-aware warmup метаданных во время активного стрима, более безопасного завершения и снижения частоты UPnP-обновлений каталога.
- DLNA/XML: исправлено полноценное XML-экранирование DIDL-Lite для имён, URL и атрибутов.
- Tests: добавлены локальные unit-тесты для путей, `Range`, XML и прогресса.
- macOS app: приложение переименовано в Home Cinema, обновлён SwiftUI-интерфейс со светлой и тёмной темой и glass-стилем.
- Build workflow: добавлены новые скрипты `build/home-cinema/build_app.sh`, `build/home-cinema/run_control_app.sh` и helper-скрипты запуска сервера внутри `.app`.
- Cleanup: удалены legacy DMG- и AppleScript-артефакты, README переписаны под новый workflow без упаковки DMG.
